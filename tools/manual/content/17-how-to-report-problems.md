> Temporary quick-start for TestFlight testers until the tutorial videos are ready.

If something is wrong, confusing, or different from this guide, I want to hear it. This beta is how we find those things before the tutorial videos — and the release — are finished.

Please send feedback by Monday, December 7.

## How to send a report

Please send bug reports with **Submit Bug Report** in the app's three-dot menu.

If you can't use that, the contact form on my website is a backup:

[larryseyer.com/pages/connect.html#contact](https://larryseyer.com/pages/connect.html#contact)

That form goes straight to my inbox. Please put “Larry Seyer Drums beta” in the message so I can find it quickly.

## What to include

The more of this you can give me, the faster I can reproduce it:

1. **What you were trying to do**, in one or two sentences.
2. **What happened**, and what you expected instead.
3. **Where you were:** standalone app, or a plug-in inside a host. If it was a host, the host's name and version, and the plug-in format (in this beta that's AUv3).
4. **The device and system:** for example “iPhone 15, iOS 18.x” or “Mac, macOS 15.x, this processor.”
5. **Larry Seyer Drums version** (this TestFlight build, as shown in About).
6. **Steps to reproduce**, starting from Quick Pick when you can. Busy Beat is a helpful starting point because I'll try it the same way.
7. **A screenshot or a short screen recording** if the problem is visual or musical. If there was a message on screen, include the exact wording (“Not enough power,” “Simple Comp is running…,” and so on).
8. **Whether it happens every time**, or only once in a while.
9. Anything you already tried (Rescan Outputs, reloading the plug-in, a different buffer size, another output device).

If the app dropped audio, note what the DSP load meter was doing, which effects were on, and how many players were playing.

If the problem is “no sound,” walk through the [“No sound?” checklist](02-getting-started.md#no-sound-checklist) first and tell me which step didn't fix it.

## What is probably not a new bug

Please still write in if you're unsure — I'd rather have a duplicate than a miss — but check [Known Gaps in This Beta](16-known-gaps.md) first. In particular, the Force Multi-Out rescan/reload step, Auto staying stereo in a plug-in, device-power messages, and features listed as not in this build are already known.
