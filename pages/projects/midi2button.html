MIDI2Button

Turns MIDI messages into keystrokes, so a controller can drive software that only listens to a keyboard.

The Problem

Plenty of useful software takes keyboard input and nothing else. If your hands are on an instrument, the keyboard is the one input you do not have free.

MIDI2Button sits in between. A pad or a foot switch sends MIDI, the application receives a keystroke, and it never knows the difference.

Key Features

  • Any message to any keystrokeNotes, CCs, and program changes all map, including modifier combinations
  • Mappings you defineSet up once and saved, so the rig comes back the way you left it
  • Several controllers at onceA keyboard, a pad, and a foot switch can all be mapped together
  • Fast enough to play againstThe keystroke arrives while the gesture is still happening
  • Stays out of the wayRuns in the background with no window to manage
