Larry Seyer Drums OSC Reference

Larry Seyer Drums has a complete OSC (Open Sound Control) implementation for controlling virtually every aspect of its operation from another app, a control surface, a script or another computer. This page lists all 1548 commands. Back to Larry Seyer Drums.

Connecting

  • On by defaultOSC control is on in every version. Turn it off or change the port in App Settings → OSC Control.
  • Receive portLarry Seyer Drums listens for OSC over UDP on port 9100 by default (9200 is the alternative in App Settings). It listens on every network interface, so it can be reached from another device on the same network.
  • RepliesAnswers are sent back over UDP to port 9101 (the receive port plus one) on the same computer.
  • Reading a valueSend an address with no argument and Larry Seyer Drums replies with its current value. Sending a value sets it and the new value comes back as confirmation.
  • Live updatesReadable values that change are sent automatically, up to 30 times a second, and a full set of current values is sent when OSC starts.
  • Argument typesArguments are 32-bit integers, 32-bit floats or strings. On/off values are sent and received as the integers 0 and 1. Addresses must match exactly; wildcard patterns are not used.
  • NumberingPlayers and song lanes are numbered 1-4 where the address says <1-4>. Everything else (mixer channels, buses, effect returns, slots, pills and energy levels) counts from 0. A range such as <0-95> means one address for each number.
